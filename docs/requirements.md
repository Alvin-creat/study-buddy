# StudyBuddy 需求文档

## 1. 项目背景

全球每年有数亿人参加各类考试，但独立备考存在信息不对称、缺乏监督、容易放弃等痛点。现有学习社交产品多局限于单一国家或语言，缺乏跨国匹配能力。

## 2. 用户角色

| 角色 | 描述 |
|------|------|
| 普通用户 | 注册并实名认证的学习者 |
| 认证用户 | 完成实名认证，可使用全部匹配功能 |
| 管理员 | 审核实名材料、处理举报、管理考试分类 |

## 3. 功能需求

### 3.1 用户注册与认证 (P0)

- **FR-01** 支持手机号（国际区号）注册登录
- **FR-02** 支持邮箱注册登录
- **FR-03** 实名认证：上传证件照 + 自拍人脸比对
- **FR-04** 证件类型：身份证、护照、驾照（按地区自适应）
- **FR-05** 认证状态：未认证、审核中、已认证、认证失败

### 3.2 个人主页 (P0)

- **FR-06** 基础信息：头像、昵称、地区、时区、母语
- **FR-07** 学习档案：目标考试、目标院校/机构、学习阶段
- **FR-08** 考试记录：已参加考试、成绩（可选公开）
- **FR-09** 搭子评价：历史搭子评分、评价标签
- **FR-10** 学习动态：打卡记录、学习时长统计
- **FR-11** 隐私设置：控制各字段的可见范围

### 3.3 考试搭子匹配 (P0)

- **FR-12** 考试类型三选一：考研 / 证书 / 等级考试
- **FR-13** 细分学科选择（如考研→计算机→408统考）
- **FR-14** 匹配条件：目标院校、专业方向、每日学习时段、所在时区
- **FR-15** 推荐算法：综合匹配度评分
- **FR-16** 手动搜索：关键词 + 多维筛选
- **FR-17** 搭子请求：发送/接收/接受/拒绝
- **FR-18** 搭子人数：支持 1v1 和小组（3-5人）

### 3.4 即时通讯 (P1)

- **FR-19** WebSocket 实时消息
- **FR-20** 消息类型：文本、图片、文件
- **FR-21** 消息翻译（非母语自动翻译）
- **FR-22** 敏感词过滤
- **FR-23** 消息已读/未读状态

### 3.5 社区与评价 (P1)

- **FR-24** 搭子互评：学习态度、出勤率、沟通能力
- **FR-25** 学习打卡：每日学习记录
- **FR-26** 经验分享帖

## 4. 非功能需求

| 需求 | 指标 |
|------|------|
| 首屏加载 | < 2s (4G 网络) |
| 消息延迟 | < 500ms |
| API 响应 | P99 < 200ms |
| 并发支持 | 10,000+ 同时在线 |
| 数据安全 | 实名数据加密存储，传输 TLS 1.3 |
| 合规 | GDPR / 个保法 / PIPL 合规 |
| 可用性 | 99.9% uptime |

## 5. 国际化需求

- 支持 7 种语言 UI
- 时区自动检测与转换
- 多币种（如需付费功能）
- 考试分类按地区差异展示
